# Data Analytics Project 1: Data Cleaning & Preparation

## Project Overview
This repository contains the deliverables for Project 1 of the DecodeLabs Industrial Training program. The objective of this project is to perform a data integrity audit and clean a raw transaction dataset of 1,200 records to achieve a 0% error rate on unique identifiers and date formatting.

## Core Objectives
* **Strategic Imputation:** Identified and resolved missing attributes in categorical columns (e.g., `CouponCode`).
* **Integrity Audit:** Audited key transaction constraints to identify and eliminate duplicate entries.
* **Standardization:** Normalized text records using Title Case and forced ISO 8601 (`YYYY-MM-DD`) formatting on date attributes.
* **Precision Tuning:** Established two-decimal float precision across all financial metrics.

## Tech Stack
* **Language:** Python 3.x
* **Libraries:** Pandas
